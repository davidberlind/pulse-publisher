Privacy Policy

Last updated: 28 September 2026

Who uses this app

Pulse Publisher is a private tool operated by its owner for their own use. It is not offered to the public.

What it accesses

The app requests only the Google Drive drive.file scope. This limits it to files and folders the app itself has created. It cannot read, list or modify any other file in the user's Google Drive.

What it does with data

The app creates Google Docs from newsletter drafts, and moves them between folders it created. It does not delete files.

Sharing and storage

No data is sold, shared with third parties, or used for advertising. The OAuth token that authorizes the app is stored only on the owner's own computer.

Revoking access

Access can be revoked at any time from the Google Account's Security settings, under third-party connections.

Contact

Questions can be raised as an issue on this project's GitHub repository.
